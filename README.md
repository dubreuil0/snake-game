# Snake Game

A classic snake game that runs in the browser, styled like the green screens of old mobile phones. It is playable in English and Turkish. The whole game is a single `index.html` file, with no installation and no dependencies.

**Play it here:** https://dubreuil0.github.io/snake-game/

## How to play

- **On a computer:** Steer the snake with the arrow keys or `W` `A` `S` `D`. Press `Space` to pause. The on-screen arrows light up as you press the keys, and you can click them with the mouse too.
- **On a phone:** Swipe on the screen, or tap the on-screen arrows. The square button in the middle pauses and resumes the game.
- The snake grows and speeds up each time it eats an apple.
- The game ends if you hit a wall or your own tail.
- Your high score is saved in your browser.
- **Languages:** The game starts in English. Use the **EN | TR** switch in the top right corner to change to Turkish. Your choice is remembered.

## Run it locally

1. Download `index.html` from this page (or use **Code → Download ZIP** to get the whole repository).
2. Double-click the file. It opens in your browser and works offline. Only the fonts are loaded from the internet, and a fallback font is used if they are not available.

## Built with

Plain HTML, CSS and JavaScript. No external libraries. The game was written with the help of AI.
